# 📚 CampusTask

Aplicativo móvel para auxiliar estudantes na organização de atividades acadêmicas.

## Normas Aplicadas
- ISO/IEC 25010 — Qualidade de Produto de Software
- ISO/IEC/IEEE 15288 — Ciclo de Vida de Sistemas

## Funcionalidades
- ✅ Registrar tarefas de estudo
- ✅ Definir prazos para atividades
- ✅ Visualizar tarefas pendentes
- ✅ Marcar tarefas como concluídas

## Documentação
Todos os artefatos de engenharia estão na pasta `docs/`:

| Arquivo | Conteúdo |
|---|---|
| `artefatos.md` | Descrição do produto e atributos de qualidade |
| `requisitos-nf.md` | Requisitos não funcionais (RNF-01 a RNF-07) |
| `decisoes-eng.md` | Decisões técnicas de engenharia |

## Tecnologias Previstas
- Flutter (Dart)
- SQLite para persistência local
- Arquitetura em camadas
